# Support

GeneWire is in research and design. There is no installable package, stable
protocol, hosted service, commercial support, or response-time guarantee.

| Need | Where to go |
| --- | --- |
| General questions or design discussion | [GitHub Discussions](https://github.com/dehghandehnaviamin/GeneWire/discussions) |
| Documentation errors or a reproducible future bug | [Issue forms](https://github.com/dehghandehnaviamin/GeneWire/issues/new/choose) |
| Features, protocol changes, or research | Appropriate issue form; see [CONTRIBUTING.md](CONTRIBUTING.md) |
| Vulnerability or sensitive security concern | Private process in [SECURITY.md](SECURITY.md) |
| Community conduct | Confidential reporting in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Search existing threads first. Provide the relevant document or commit, expected
and observed behavior, and a minimal synthetic example when appropriate. Never
attach patient data, credentials, sensitive logs, or proprietary datasets.
Do not use public discussions for vulnerability details or conduct reports.
